# Profile documents

A profile's **Documents** tab lists the documents kept for the person:
identity cards and passports, contracts, NDAs, badge photos and others, each
with its **Title**, **Kind**, **Version**, **Valid until** date and when it was
uploaded.

## Uploading

**Upload document** in the profile's menu asks for the **Kind**, a **Title**
and the **File**: a PDF, PNG, JPEG or WebP file up to 10 MB. The file is sent
with the request and stored by the platform itself as a sensitive file of the
organization; it is never uploaded from the browser to the file storage, and
it is not kept in a form draft. A file of another type, or a larger one, is
refused before anything is sent.

The upload is not repeated automatically when the answer is lost: look at the
Documents tab first, since sending it again stores a second copy.

An erased profile takes no documents.

## Opening

**Open file** asks the platform for a short-lived link to the file and opens
it in a new tab. Each opening is written to the audit log. The link is never
kept: every click asks for a new one, so a page left open for a long time still
opens the file.

## Changing and removing

**Edit** changes the title, kind, version and validity; the file itself
cannot be replaced (upload a new version as a new document). Documents are
not deleted from the console. When two profiles are merged, the documents of
the merged profile move to the kept one; erasing a person's data removes them.
