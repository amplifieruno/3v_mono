# Segment templates

A **segment template** is a ready-made set of conditions for dynamic
segments, such as *Frequent visitors* or *New faces this week*.

- **Built-in** templates come with the platform and are read only.
- The organization can add **its own** templates; they can be changed and
  deleted. Changing a template does not change the segments already created
  from it.

## Create segment

**Create segment** on a template creates a dynamic segment with the
template's **Members are** (profiles or identities) and a copy of its
conditions, under a name of its own; the description is the template's
unless you write one. The new segment is evaluated within a minute or two.
The template's **Segments created from it** tab lists them.

If the template's conditions no longer fit the organization (for example, a
custom field they name was switched off), the segment is not created and the
form says which condition is at fault.
